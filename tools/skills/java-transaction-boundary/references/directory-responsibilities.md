# 事务相关目录职责（管事务流程中的边界划分，设计事务前先查）

保持从协议入口到用例服务、事务执行器、持久化与外部适配器的单向依赖。具体目录名必须匹配项目现状。

| 组件 | 负责 | 不负责 |
|---|---|---|
| 协议入口 | 校验、调用和响应适配 | 事务脚本、锁、Mapper 调用 |
| 用例服务 | 上下文、权限、分支、锁和事务执行器调用 | 原始协议、巨大原子写入脚本 |
| 事务执行器 | 单一原子一致性集合、CAS、必需写入和明确结果 | 权限、锁获取、响应格式 |
| 规则/策略 | 纯业务判断与计算 | I/O、事务、流程编排 |
| 查询支持 | 有界读取与批量补全 | 写事务、协议包装 |
| 客户端 | 远程协议适配与错误映射 | 本地事务和状态机所有权 |
| 持久化 | 查询、更新、CAS 原语 | 跨聚合编排、远程调用 |

通常置于事务外：请求校验、身份与权限、锁获取、分支选择、响应转换、回滚后的日志或收敛。

通常置于事务内：预期状态的 CAS、聚合及明细写入、已接受设计要求的参与者调用、最终状态更新与显式结果构造。
